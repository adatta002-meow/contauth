What happens behind the meter

Capture

Only timings and pointer coordinates: never which key you press or what you type.

Features

21 features per window: typing rhythm, pointer speed, clicks, scrolling, pauses, pointer-path regularity.

Models

Cold start uses the population model trained on 705 real sessions. After 12 clean windows a personal Isolation Forest takes over, with your own calibrated threshold.

Zero Trust

Behaviour alone can force a password re-check, never a termination. Cookie theft and bots end the session and lock the account for 15 minutes.

How the full system measured on real data

The population model here is the server's trained model, exported exactly (scores match Python to 6 decimals). Personal profiles use an Isolation Forest; the server additionally uses a One-Class SVM and, once several users are enrolled, a supervised ExtraTrees + logistic-regression model.
