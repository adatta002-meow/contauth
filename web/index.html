About

A session should stay yours after you log in

ContAuth is an East West University CSE400B capstone: continuous authentication for web sessions using behavioural biometrics and Zero Trust controls.

The gap

Login is checked once

Most web apps trust a session until it expires. A stolen cookie or an unlocked laptop keeps that trust.

The idea

Keep checking, quietly

Everyone types and moves a mouse a little differently. Measuring that rhythm continuously costs the user nothing.

The response

Trust is earned, not granted

When behaviour drifts, the system asks for your password; when the evidence is certain, it ends the session.

Features

How it works, layer by layer

The same pipeline runs in the Flask server and in this page. Hover a card to tilt it.

01

Behaviour capture

Only timings and pointer coordinates are recorded: never which key you press, never what you type.

02

21 behavioural features

Typing rhythm, pointer speed and travel, clicks, scrolling, idle pauses and pointer-path regularity, every 5 seconds.

03

Trained and personal models

Cold start uses the population model trained on 705 real sessions. After 12 clean windows, a personal Isolation Forest takes over.

04

Zero Trust engine

Risk = 0.70·B + 0.10·C + 0.10·D + 0.10·S. Low allows, medium monitors, high asks for your password, critical ends the session.

05

Attack detection

Stolen cookies, scripted bots, new networks and new devices are caught by deterministic rules that act at once.

06

Admin console

Every session live, per-window risk breakdowns, a filterable security log, and remote terminate, lock, unlock and reset.
